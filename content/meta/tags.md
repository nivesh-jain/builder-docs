# Tag Taxonomy

This is the canonical list of tags used across the builder garden. Keep it small and opinionated so tags stay meaningful.

## Core tags

- `platform` — high-level information about the builder platform itself.
- `guide` — step-by-step instructions or how-tos.
- `concept` — conceptual explanations and mental models.
- `decision` — architecture or product decisions and their rationale.
- `experiment` — spikes, prototypes, or exploratory work.
- `api` — endpoints, contracts, or integration details.
- `meta` — notes about the garden itself.

When adding new notes, pick 1–3 tags from this list. If you truly need a new tag, add it here with a short description.
